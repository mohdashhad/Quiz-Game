# Quiz-Game
Welcome to the Kaun Banega Crorepati (KBC) game, a Python-based quiz game inspired by the iconic Indian TV show! Built with Pygame, this game brings the thrill of KBC to your screen with engaging multiple-choice questions, lifelines, and immersive sound effects. Test your knowledge, use strategic lifelines, and aim to win the virtual crore!

Features





Interactive Quiz Gameplay: Answer a series of multiple-choice questions with increasing difficulty.



Lifelines: Utilize classic KBC lifelines like 50-50, Audience Poll, and Phone-a-Friend to boost your chances.



Sound Effects: Enjoy immersive audio feedback for correct/incorrect answers and game events using Pygame’s sound module.



Prize Ladder: Progress through a monetary reward system, from ₹1,000 to ₹7 Crore.



Graphical Interface: A sleek Pygame UI with a question display, option buttons, and prize ladder.



Randomized Questions: Questions are shuffled from a predefined dataset for replayability.
